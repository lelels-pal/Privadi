# Release Notes for Privadi v1.0.0

## New Features
- **Dark Mode Support**: Added toggle in dashboard to switch between light and dark themes.
- **Enhanced Accessibility**: Improved VoiceOver labels and dynamic type support.
- **Offline Breach Check**: Local email security verification against bundled breach database.
- **CI/CD Pipeline**: Automated builds and tests via GitHub Actions.

## Improvements
- Restructured UI for better responsiveness on iPhone/iPad.
- Added privacy policy integration and manifest compliance.
- Optimized performance for large dataset scans.

## Bug Fixes
- Fixed build errors and syntax issues in code.
- Corrected variable scoping in DashboardView.

## Security
- AES-256 encryption for vault data.
- Keychain integration for secure key storage.
- No data collection or external transmissions.

## Known Issues
- Dark mode may not fully adapt custom themes.
